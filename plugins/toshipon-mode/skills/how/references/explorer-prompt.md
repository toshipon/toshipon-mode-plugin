# Explorer Prompt Template

このテンプレートから各 explorer サブエージェントのプロンプトを組み立てる。プレースホルダを埋めること。

---

他の explorer が同じサブシステムの異なる切り口を並列に調査している。すべてを網羅しようとしないこと。割り当てられたアングルに集中し、深く掘り下げること。

## Output

### Components Found
主要な型、サービス、クラス、抽象。それぞれについて: 名前、ファイルパス、それが何をするかの一文説明。

### Flow
実行フローをステップごとに。各ステップについて: どの関数/メソッドが実行されるか、どのファイルにあるか、何をするか、次に何を呼び出すか。ステップ間を流れるデータを含める。

### Files Read
調査中に読んだすべてのファイル。explainer がそれらを参照できるように。

### Boundaries
このサブシステムがコードベースの他部分と接続する場所。入力と出力。

### Non-Obvious Things
意外なこと、歴史的な経緯があるもの、誤解しやすいもの。ある動き方をするように見えて実は違う動き方をするもの。

### Open Questions
完全にたどれなかった、あるいは理解できなかったもの。ギャップについて正直であること。
