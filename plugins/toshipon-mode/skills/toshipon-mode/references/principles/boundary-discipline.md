# Boundary Discipline

データがシステム境界（CLI 引数、設定ファイル、外部 API、ネットワーク）を越える場所で、検証し、型を絞り込み、エラーを扱う。内側では型を信頼し、再検証も冗長な nil チェックもしない。生データは境界でドメイン型にパースし、transport やフレームワークの型を public な面に出さない。ビジネスロジックはフレームワークに依存しない純粋関数に置き、それを呼ぶシェルは薄くする。

テストは 2 つある。このデータは今まさに境界を越えているか。越えていないなら、その検証は冗長である。これはシェルが呼ぶだけの純粋関数にできるか。できるなら抽出する。
