# Fix Root Causes

症状が表に出た場所ではなく、故障そのものを直す。根本原因とは、システムがすべきでないことを最初にした場所、または扱うべき state を扱えなかった最初の場所である。

- まず再現させる。答えがコードの中の誤った判断になるまで「なぜ」を問う。行き詰まったら計測し、実際の state を読む。
- 症状を引き起こした state が正当かを問う。正当なら、壊れた場所でその state を扱う。本来存在してはならないなら、そこにチェックを足すとバグが隠れるので、その state を生み出したものを探す。ガード、retry、握りつぶしたエラー、clamp した値、捨てた state は、バグを隠すよくある手口である。
- 個別の事例ではなくパターンを直す。同じ故障を持つ箇所をすべて見つける。
- 決め手となった事実を見つけるのに深い掘り下げが要ったなら、最初の一目でそれを示せたはずの、安価で常時動くシグナルを提案する。
