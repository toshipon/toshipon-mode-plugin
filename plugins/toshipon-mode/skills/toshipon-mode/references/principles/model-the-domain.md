# Model the Domain

ドメインを条件分岐に散らばせず、データ構造にエンコードする。正しい構造は無効な状態を表現できなくし、分岐を削除する。

散らばった boolean やフェーズのチェックの代わりに state machine を、ゆるいパラメータの代わりに型付きモデルを、ファイル間に散らばる分岐の代わりに map、registry、discriminated union を、場当たり的な mutation の代わりに reducer を使う。アクセスパターンが求めるなら index、queue、正規化されたコレクションを使う。

無理に押し付けない。形状が明確でローカルで、成長しそうにないなら素朴なコードのままにする。分岐も無効な状態も減らさずに間接参照だけを増やす抽象化は疑う。

これを飛ばしたサインは、if/else チェーンに分岐を 1 つ足すだけの機能や、最初の boolean と同期させ続けなければならない 2 つ目の boolean である。
