# Minimize Reader Load

reader load とは、読み手がコードを理解するために払う作業量である。2 つの独立した軸がある。問いと答えの間でたどる層の数と、頭の中に保持する隠れた state や可変な state の量である。両方をガードする。

- 転送するだけの層は畳む。呼び出し元が 1 つの wrapper、2 つ目の実装がない adapter、pass-through のメソッドはインライン化する。
- state のスコープを縮める。mutation より return、フィールドよりローカル変数、モジュール state よりフィールド、グローバルよりモジュール state を選ぶ。同期させるのではなく導出する。
- 不変条件は各利用箇所ではなく境界で一度だけ名付ける。

テスト。新しい読み手が「X はどこから来るのか」「何が X を変えうるのか」に 30 秒以内で答えられるか。答えられないなら、層か state を削る。
