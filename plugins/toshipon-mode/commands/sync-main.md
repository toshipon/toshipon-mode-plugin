# Sync Main Branch

メインブランチの最新を現在のブランチに取り込みます。

## 実行内容

1. リモートのメインブランチを自動検出（main, master, develop など）
2. リモートから最新を fetch
3. 現在のブランチにメインブランチの変更を merge

## 使用方法

作業開始前や、長時間作業した後にメインブランチの最新を取り込みたい場合に実行してください。

---

以下のスクリプトを実行してメインブランチを同期してください：

```bash
${CLAUDE_PLUGIN_ROOT}/scripts/sync-main-branch.sh
```

実行結果を確認し、コンフリクトが発生した場合は解決を手伝ってください。
