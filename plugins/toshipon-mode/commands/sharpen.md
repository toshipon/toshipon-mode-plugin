# /toshipon-mode:sharpen

このタスクを、大きくではなく深くしたい。書き直す前に、次の 4 つをする。

1. この分野の一流の専門家なら、ここで何をするか。そのうち、自分が頼んでいないものを言う。
2. 誰かがすでに消化したものではなく、専門家が出発点にする最も生の材料を名指しする。
3. 専門家が使う具体的な方法と道具を名指しする。
4. あなたでも私でもない何が、結果が正しいことを示すかを言う。

そのうえで、まさにそれを求めるように私のプロンプトを書き直す。返すのは書き直したプロンプトだけにする。タスクそのものはしない。

私が決めるべき選択は、自分で決めずに開けておく。
